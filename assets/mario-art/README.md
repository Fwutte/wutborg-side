# Mario landscape illustrations

Created for this project on 2026-09-11 with the built-in imagegen tool. All three original PNG files are 1536 × 1024. No external image service is used by the game. The winter and cavern images load only when their respective level types are shown. Code in `js/mario-art.js` draws the foreground, characters and effects and provides a procedural background while an image loads or if loading fails.
